# 0007 路由：L0 直通 → Hermes → 自研循环

引入 Hermes 后必须回答"什么时候用它"。三条路径的取舍：

| 路径 | 触发 | 理由 |
|---|---|---|
| L0 直通 | 高频槽位指令命中 | <100ms、0 成本、100% 可复现 |
| Hermes | 多步/规划/带附件/显式要求深度思考 | 任务拆解与自主执行是它的强项 |
| 自研循环 | Hermes 未就绪，或单轮问答 | 子进程启动开销不划算；且必须保证降级可用 |

"复杂"判定用纯规则（`src/route.ts`），不调模型判定——判错一次就多花一次模型调用。
规则可被设置覆盖，但默认值必须保守：宁可走自研循环，也不要把简单指令丢给子进程。
