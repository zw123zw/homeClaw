# 0005 L2 命名统一为 Hermes，本期以自研薄循环实现

L2 在原文档中称 OpenClaw，但该名称指向的是一个未在本仓库落地的第三方内核：代码里只有字符串痕迹，没有进程、没有依赖。继续沿用会造成"文档描述的架构"与"实际运行的架构"长期不一致。

本次统一：L2 对外名称改为 **Hermes**（审计 actor 为 `ai:hermes`，配置项 `GATEWAY_DRIVER` 取值 `hermes`），文档、术语表、部署目录同步。L2 的对外接缝（信封协议、MCP 客户端、模型适配）保持不变，因此替换内核实现时 L1 与 L3 零改动。

本期 L2 由 `apps/gateway` 的自研薄循环承担：8 个模块，依赖仅 fastify / cors / zod / contracts。不引入 agent 框架，理由是该层当前只需要 chat + tools + MCP + SSE 四项能力，而沙箱、取消语义、工具中间态、断线补齐这四件事无论用哪个框架都要自己实现；引入框架的收益低于重做这四件事的成本。若后续需要通用电脑操控或多 agent 编排，再评估第三方内核。

**Status**: superseded by ADR-0006（L2 不再由自研薄循环承担，改为 vendor Hermes + 子进程接入；自研循环仅保留为降级路径）。本文的"命名统一为 Hermes"仍然有效。
